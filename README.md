# Playwright Python Automation Framework

A test automation framework built with **Python**, **Playwright**, and **Pytest**, designed for validating both backend (REST APIs) and frontend (UI) workflows.

## 🚀 Tech Stack
* **Language:** Python
* **Test Runner:** Pytest
* **Automation Tool:** Playwright (Sync API)
* **Target Systems:** ReqRes (API Testing) & SauceDemo (E2E UI Testing)
